## Known limitations (deliberate, not defects)

- **`data/cookie_cats.csv` is not committed.** It is Kaggle-licensed and 2.7 MB; the loader verifies its MD5 against the provenance hash recorded in `sql/phase3_00_create_metadata.sql`.
- **Business impact is a proxy, not measured revenue.** ARPDAU $0.10 is a public benchmark, and D7 retention stands in for stickiness/LTV. The dataset carries no monetisation columns, so the dollar figure scales an assumption — the direction and the relative size of the effect are what the analysis actually establishes.
- **No Power BI dashboard.** Dropped deliberately (DEC-13): the dataset is a static snapshot with no time dimension, so a dashboard would add motion without adding information.
